# Sigma hotfix V2 — compatibilité Sprints 252, 254 et 315–329

Le test du Sprint 252 utilise précisément ce contrat historique :

```js
createIntegrationOrchestrator({
  provider,
  accountId,
  kind,
  fetchPage
}).sync()
```

Le hotfix précédent ne restaurait pas cette branche de synchronisation. Cette
version fusionne les deux API dans le même module :

- ancien pipeline delta → normalisation → lot d’import ;
- nouveau registre d’adaptateurs et synchronisation par identifiant ;
- ancien `validateIntegrationHub` ;
- nouveau `validateIntegrationOrchestrator`.
