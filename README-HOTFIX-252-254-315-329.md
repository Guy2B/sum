# Sigma hotfix — compatibilité Sprints 252, 254 et 315–329

Ce correctif rétablit la compatibilité entre les anciens contrats du module
`integrations` et la nouvelle vague 315–329 :

- `sync()` sans identifiant fonctionne lorsqu’un seul connecteur est configuré ;
- les anciens connecteurs exposant `sync()` ou `fetch()` restent supportés ;
- `validateIntegrationHub` est rétabli ;
- `validateIntegrationOrchestrator` reste disponible.
