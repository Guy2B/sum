# W7.1 — Sprint 76: Universal Connector Core

## But

Installer une couche universelle et additive pour les futurs connecteurs Sigma,
sans modifier le moteur de décision, les règles de signaux, l’interface ni les
connecteurs existants.

## Livrables

- `ConnectorRegistry` : enregistrement, résolution et filtrage par capacité.
- `ConnectorManager` : connexion, synchronisation, déconnexion et état de santé.
- contrat minimal obligatoire pour chaque connecteur ;
- capacités normalisées ;
- erreurs normalisées avec indication `retryable` ;
- six tests automatisés.

## Flux préparé

```text
Provider adapter
    ↓
Universal Connector Core
    ↓
Provider payload unchanged
    ↓
Future normalization layer (Sprint 78+)
    ↓
Sigma universal signals
```

Le Sprint 76 ne transforme encore aucune donnée Microsoft et n’ajoute aucun
secret OAuth. Il établit uniquement le socle technique commun.

## Fichiers ajoutés

- `modules/connectors/universal-connector-core.js`
- `tests/connectors/universal-connector-core.test.js`
- `docs/W7.1-SPRINT-76.md`

Le script `check` de `package.json` est complété de manière idempotente afin que
le nouveau module soit couvert par `npm run check`.

## Critères d’acceptation

1. Le registre refuse un connecteur incomplet ou dupliqué.
2. Le gestionnaire délègue les opérations sans altérer leurs résultats.
3. L’état de santé suit les connexions et synchronisations.
4. Les erreurs temporaires (429, 5xx, timeout) sont marquées réessayables.
5. Les tests existants restent inchangés.
6. Aucun fichier métier ou UI n’est modifié.
