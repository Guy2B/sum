# W7.1 — Sprint 77: OAuth Framework

## But

Fournir une couche OAuth 2.0 générique, testable et indépendante des fournisseurs,
préparant Microsoft Outlook puis les futurs connecteurs Apple et Google.

## Capacités livrées

- génération PKCE S256 ;
- génération et validation de l’état OAuth ;
- construction de l’URL d’autorisation ;
- validation du callback ;
- échange du code d’autorisation ;
- renouvellement d’un jeton ;
- conservation du refresh token lorsque le fournisseur ne le renvoie pas ;
- seuil configurable avant expiration ;
- révocation locale ;
- stockage abstrait des jetons ;
- normalisation des erreurs temporaires.

## Limites volontaires

- aucun identifiant client réel ;
- aucun secret dans le dépôt ;
- aucun endpoint Microsoft codé en dur ;
- aucun appel réseau direct dans le module ;
- aucun changement d’interface ou de moteur de décision.

Le transport HTTP et le stockage persistant seront branchés dans les sprints
d’intégration fournisseur. Le stockage livré ici est uniquement une
implémentation mémoire de référence pour les tests et les environnements locaux.
