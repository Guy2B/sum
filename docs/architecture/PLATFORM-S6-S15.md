# Architecture plateforme S6–S15

Flux cible : Connecteurs → Index/Graph → Mémoire → Planificateur → Agent → Politique → Exécution → Audit.

Principes : isolation par workspace, déterminisme, provenance, moindre privilège, approbation humaine des effets externes, compatibilité ascendante et absence de dépendance runtime supplémentaire.
